# Niña Blanca

Public sanctuary site for prayer, petitions, and study of Santa Muerte in all her aspects.

Live domain (after DNS): https://ninablanca.com

## Local

1. Copy `.env.example` to `.env.local` and add `DATABASE_URL` (Neon: Connect → pooled connection string).
2. `npm install`
3. `npm run dev`

Design references from Google Stitch live in `design/`.
