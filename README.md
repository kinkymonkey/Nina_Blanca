# Niña Blanca

Public sanctuary site for prayer, petitions, and study under the white aspect of Santa Muerte.

Live domain (after DNS): https://ninablanca.com

## Local

1. Copy `.env.example` to `.env.local` and add `DATABASE_URL` (Supabase: Project Settings → Database → Connection string → URI).
2. `npm install`
3. `npm run dev`

Design references from Google Stitch live in `design/`.
